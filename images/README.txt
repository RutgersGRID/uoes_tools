The site header looks for the official Rutgers logo at:

    images/rutgers_primary_mark.svg

Until that file exists, pages automatically fall back to loading the
logo directly from the live site:

https://uoes.rutgers.edu/profiles/contrib/rutgers/themes/rutgers_main/pattern_lab/source/images/icons/Rutgers_Primary_Mark.svg

To make the logo work offline (recommended), open that URL in a
browser, save the file into this folder as rutgers_primary_mark.svg,
and the pages will use the local copy automatically.
