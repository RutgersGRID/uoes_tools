images/rutgers_primary_mark.svg is the official Rutgers logo used in the
site header of every page. Keep the filename all lowercase: Linux and
GitHub Pages are case-sensitive, and the pages reference it exactly as

    images/rutgers_primary_mark.svg

If the local file is ever missing, each page's onerror handler falls back
to loading the logo from the live site:

https://uoes.rutgers.edu/profiles/contrib/rutgers/themes/rutgers_main/pattern_lab/source/images/icons/Rutgers_Primary_Mark.svg
